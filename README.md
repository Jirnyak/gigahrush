## 📖 About

**GIGAH|RUSH (ГИГАХРУЩ)** is a post-apocalyptic survival game set in the infinite brutalist depths of a Soviet *Khrushchyovka* — an endless concrete apartment block on the verge of **Samosbor** (spontaneous structural collapse).

You are a **Liquidator** — equipped with a Geiger counter, flashlight, and sheer willpower — tasked to navigate the never-ending floors before the next Samosbor event seals you inside forever.

A joint open-source project by **Jirnyak** & **Adolf Petushkov**, built with love for anonymous internet culture, industrial concrete aesthetics, and the legend of Soviet liquidators.

## ✨ Features

| Feature | Description |
|---|---|
| 🏢 **Infinite Procedural Block** | Algorithmically generated floors, locked flats, utility shafts, and basement sections — every run is unique |
| 🚨 **Samosbor Event System** | Dynamic countdown to structural collapse — seal the blast doors or get buried in concrete |
| 🔦 **Liquidator Equipment** | Geiger counter, flashlight, pry bar, gas mask — authentic Soviet survival gear |
| 🛠️ **Full Moddability** | Fork it, skin it, reskin it — total conversion mods, custom floor packs, and texture overhauls welcome |
| 🌐 **WebGL / HTML5** | Runs instantly in any browser — no install required |
| 📜 **True People's License** | 100% open source, no paywalls, no NFTs, no corpo nonsense |

## 🚀 Getting Started

### Play Online (Instant)
👉 **[gigahrush.github.io](https://gigahrush.github.io)** — no install required

### Run Locally
```bash
git clone https://github.com/Jirnyak/gigahrush.git
cd gigahrush
# Option 1: Python
python -m http.server 8080
# Option 2: Node.js
npx http-server ./ -p 8080
# Open http://localhost:8080
```
