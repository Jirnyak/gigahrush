# viewmodels/ — руки от первого лица, нарисованные вручную

Сюда кладут PNG для вьюмодели: то, что боец держит в руках, его же глазами.
Процедурный спрайт остаётся умолчанием и рисуется всегда; файл отсюда просто
перебивает процедуру для одной пары «вещь + кадр». Ничего регистрировать в коде
не нужно — достаточно положить файл и запустить запекатель.

## Куда класть

```txt
viewmodels/
  <itemId>/
    idle.png
    fire.png
    swing.png
    swing2.png
    reload.png
```

- `<itemId>` — идентификатор предмета из `src/data/items.ts`: `makarov`,
  `flashlight`, `psi_strike`. Строчные буквы, цифры и подчёркивания.
- Имена кадров закрыты списком: `idle`, `fire`, `swing`, `swing2`, `reload`.
  Обязателен только `idle`; остальные — по мере надобности. Кадра нет — этот
  кадр рисует процедура, и это нормально.
- Кириллица, пробелы и `.DS_Store` в путях запрещены.

## Формат

- **Строго 128×128**, 8-битный RGBA PNG, без интерлейса. Другой размер — ошибка,
  а не повод подогнать: у руки положение дула, кисти и нижнего среза в кадре и
  есть замысел. Кадр ложится в холст один в один, ничего не обрезается и не
  масштабируется.
- Холст рисуется 1:1 в кадр 320×200, отсчёт от левого верхнего угла.
- Прозрачный фон. Полностью пустой кадр — ошибка: он бы молча стёр вещь из рук.
- Все кадры одной вещи стоит рисовать в одной сетке: покачивание, отдача, увод и
  наклон делает движок сдвигом холста, а не отдельными картинками.

## Что запустить

```bash
node scripts/generate-viewmodel-sprites.mjs
```

Запекатель кладёт пиксели в `src/render/viewmodel/generated_frames.ts` и правит
`src/data/viewmodel_art_manifest.ts`: дописывает новые строки, убирает строки
исчезнувших файлов и переписывает `sourcePath`, `sha256`, `width`, `height`.
Поля `slot` (`weapon` — правая рука, `tool` — левая), `author` и `consent`
человек ставит сам, и перегенерация их не трогает. Новая строка получает
`slot: 'weapon'` — для фонаря, ключа и прочего левого его надо поменять руками.

Сгенерированные файлы **коммитятся**: браузер PNG не читает никогда, в сборку
уезжает только TypeScript.

## Как посмотреть, не запуская игру

```bash
npx tsx scripts/viewmodel-preview.ts makarov:idle makarov:fire --out /tmp/vm.png
npx tsx scripts/viewmodel-preview.ts --slot tool flashlight:idle --out /tmp/vm.png
```

Если после запекания в превью видно вашу картинку, а не процедурный силуэт, —
подмена сработала.
