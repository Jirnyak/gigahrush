❓ Frequently Asked Questions

Technical specifications, gameplay mechanics, and open-source engine design.

How does the Cellular Automata 4-5 rule generate connected dungeons?

The dungeon begins with a 45% random wall noise distribution. Four smoothing iterations apply the standard 4-5 rule: any tile with ≥5 wall neighbors within its 3x3 kernel becomes a solid wall; otherwise it becomes floor. Finally, a flood-fill algorithm identifies all disconnected cave chambers and automatically carves orthogonal corridors to ensure 100% path connectivity.

What is the 0x100 discriminator in the monster catalog?

In Timaert, humanoid NPCs have full Oblivion-style CharacterSheets with skills and perks (kind < 8). Creatures and monsters are sheet-less data rows in fauna.cpp keyed with the bitwise flag (0x100 | index). This keeps NPC dialogue logic strictly decoupled from wildlife combat loops.

Does Timaert run entirely client-side without external dependencies?

Yes. This web demonstration is 100% self-contained with zero CDN calls, pure HTML5 Canvas raycasting, and Web Audio API procedural sound synthesizers.

How is the Bresenham Line-of-Sight Fog-of-War calculated?

From the player's coordinate, discrete integer Bresenham rays are cast to all perimeter points of a 7.5-tile circle. Rays terminate upon intersecting solid cave walls, revealing the wall facet while occluding tiles behind it. Explored tiles remain rendered at a dimmed 18% ambient parchment brightness.
